You should have HTML and CSS knowledge in order to use this template, and a willingness to learn static sites (specifically 11ty). You will need to use a code editor such as Visual Studio Code. 

Some information about 11ty can be found at [11ty.rocks](https://11ty.rocks) and [learneleventy.dev](https://learneleventy.dev)

Learn more about how the template works, and download it, on my Github here.

You can make this page a liquid or html page and do whatever you wish with it. I based it on old websites "click here if you understand what fan content is" landing pages. 

The basic theme of this site is designed to be very simple but appealing and functional on desktop and mobile.

Feel free to use this template as you wish. Just have common sense, and don't claim as your own.

Some people use [status.cafe](https://status.cafe) to have an update log. You can also use this basic status box:

By the way, a good way to get your site out there is to join webrings, and also comment on the profiles or guestbooks of other sites you admire! An example is the [fanfiction webring](https://ficring.neocities.org). You can also create 88x31 buttons or 200x40 banners to advertise your site by letting other people link to you.

You can also make RSS feeds that people can subscribe to, there's one set-up for the novels/fics collection here: [feed.xml](/feed.xml)
